# Relatorios locais de otimizacao

`benchmark_headless.py` pode exportar relatorios JSON nesta pasta.
Esses relatorios sao artefatos locais de medicao e nao devem ser usados como
fonte de verdade do codigo.

Para comparacoes oficiais da auditoria atual, use
`REGISTRO_BENCHMARK_AUDITORIA.txt` e os resultados do benchmark de substrato em
`tests/substrato_de_teste/resultados_benchmark/`.
