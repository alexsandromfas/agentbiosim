# AgentBioSim Visual Mock - C++ / SFML

Este prototipo e isolado do AgentBioSim em Python. Ele serve apenas para avaliar o visual de uma janela SFML/C++ antes de qualquer decisao sobre trocar o Pygame.

## Como rodar

Clique duas vezes em:

`run_visual_mock.bat`

O script configura CMake, compila o executavel e abre uma janela propria.

## O que ele mostra

- Substrato circular tipo placa de Petri.
- Organismos falsos com movimento fluido.
- Predadores falsos.
- Particulas de comida.
- Halos, trilhas, visao setorial e gradientes.
- Menu lateral com controles visuais.

Nao existe rede neural, evolucao, importacao, labels, saves ou qualquer integracao com a simulacao principal.
