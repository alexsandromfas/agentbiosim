# Arquivos arquivados

Esta pasta guarda copias historicas que nao sao fonte ativa da simulacao.

- `controllers_fixed.py`: variante antiga de `sim/controllers.py`, sem imports vivos.
- `ui_tk.txt`: copia antiga da interface Tk.
- `test_pyqt6_pygame.py`: prototipo grande/legado de UI PyQt/Pygame.

Arquivos nesta pasta nao devem ser usados como ponto de manutencao principal.
