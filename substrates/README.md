# Exports locais de substratos

Esta pasta e usada pela UI para exports manuais e autosaves de substrato.
Esses arquivos podem ficar grandes rapidamente e devem ser tratados como dados
locais de execucao.

Substratos pequenos e intencionais para documentacao devem ir para `examples/`.
O substrato fixo de benchmark permanece em `tests/substrato_de_teste/`.
