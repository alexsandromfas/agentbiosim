# Exemplos versionados

Use esta pasta para exemplos pequenos, intencionais e revisaveis.

Dados locais de treino, autosaves, exports manuais e relatorios de benchmark nao
devem ser adicionados aqui automaticamente. Antes de versionar um exemplo,
reduza o arquivo ao minimo necessario e documente o que ele demonstra.

O substrato canônico usado pelo benchmark automatizado fica em
`tests/substrato_de_teste/`, pois ele faz parte da suite de validacao.
